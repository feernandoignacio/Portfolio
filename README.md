# Portfólio

Meu portfólio como desenvolvedor front-end: apresentação, skills e projetos que construí.

**Ver online:** https://feernandoignacio.github.io/Portfolio/

## O que tem

- Apresentação e curiosidades sobre mim
- Skills de front-end e back-end
- Projetos: Job Application Tracker, BioGarden Paisagismo e Funcionou pra mim
- Troca de idioma: textos carregados de um arquivo JSON (`assets/lang/idiomas.json`)
- Currículo em PDF

## Tecnologias

- HTML5
- CSS3
- JavaScript (puro), com componentes para menu, idioma e responsividade

## Como rodar

O site carrega o JSON de idiomas com `fetch`, então use um servidor local, por exemplo a extensão Live Server do VS Code, em vez de abrir o arquivo direto.

```bash
git clone https://github.com/feernandoignacio/Portfolio.git
```
